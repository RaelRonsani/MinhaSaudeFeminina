Minha saúde feminina.
Um aplicativo Android desenvolvido para auxiliar no acompanhamento da saúde feminina, oferecendo ferramentas de monitoramento de ciclo e acesso a informações confiáveis.

Funcionalidades:
Monitoramento de Ciclo: Um calendário intuitivo para registrar e acompanhar o ciclo menstrual.
Conteúdo Informativo: Seção dedicada a notícias e artigos atualizados sobre saúde e bem-estar.
Perfil Personalizado: Cadastro de perfil da usuária para uma experiência mais assertiva.

Tecnologias Utilizadas:
Linguagem: Kotlin
IDE: Android Studio
Banco de Dados: Supabase (PostgreSQL)
